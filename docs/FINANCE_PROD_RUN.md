## 5. Структурные изменения (без изменения цифр)

- **ОПиУ:** строки «Операционные расходы» (`expenses` → `opex`), «Чистая прибыль» и
  «Чистая маржа» (`profit` → `net`, «Рентабельность» → «Чистая маржа»), «Справочно:
  вложено в оборудование и цех» (`investments` → `capex`). «Потери материала»
  переехали из-под расходов в себестоимость. Добавлены EBITDA, амортизация,
  операционная прибыль, проценты, налог, маржи на каждом итоге. Все пустые статьи
  расходов по-прежнему видны (найдено прогоном и возвращено, есть тест).
- **ОДДС:** суммы те же; добавлен блок «вне потока» (в сентябре пуст) и отметка
  «сходится с кассовой книгой». Строка «Возвраты клиентам» видна всегда, как раньше.
- **График по дням:** поля итогов `variable`/`fixed` → `expenses`/`below`, у дня —
  `opex`, `depreciation`, `interest`, `tax`.
