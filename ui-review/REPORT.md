  всё, ради чего сделаны реквизиты организации.
- ✅ **Починено:** окно печати выносится порталом в `<body>`
  (`components/PrintHost.jsx`), в `@media print` спрятан весь `#root` (у него
  `min-height: 100vh`, и пустой корень уводил лист на вторую страницу). Проверка

### 2. Касса считает заказ на 1 сом дешевле сервера → «Вся сумма» оставляет долг

- Скрины: [31-B-cut-side-filled.png](31-B-cut-side-filled.png) (касса: площадь
  0.553, материал 830, итого **978**),
  [33-B-order1-receipt-modal.png](33-B-order1-receipt-modal.png) (сервер:
  0.554 кв.м, 831, итого **979**, статус «Ожидает оплаты»),
  [37-B-receipts-list.png](37-B-receipts-list.png) (плитка «Долг 1 сом», кнопка
  «Оплатить» у только что полностью оплаченного чека),
  [40-B-print-check-r1.png](40-B-print-check-r1.png) («Оплачено 978 · Долг 1»).
- Воспроизведение: Продажа → «Акрил 3мм» (1500 сом/кв.м, рез 120 сом/пог.м) →
  режим «Одна сторона», ширина 0.45, длина 1.23 → Добавить → «Вся сумма» →
  Оформить.
- Руками: 0.45 × 1.23 = 0.5535 кв.м × 1500 = 830.25 → вверх **831**; работа
  1.23 × 120 = 147.6 → **148**; итого **979**. Сервер прав, касса ошибается.
- Причина: касса режет площадь до 3 знаков (`+(w*l).toFixed(3)` → JS даёт
  `0.553`, а не `0.554`) и уже её умножает на цену; сервер считает точную
  площадь. Плюс «Вся сумма» шлёт число, посчитанное кассой
  (`setPrepay(String(total))`), а не флаг `pay_full`, который у бэкенда есть
  специально для этого случая (`create_sale(pay_full=True)`, во фронте не
  используется ни разу). Любое расхождение округлений превращается в фантомный
  долг или сдачу.
- Побочно: та же деталь показывает разную площадь на разных экранах — 0.553 в
  кассе, 0.554 в чеке.
- ✅ **Починено:** площадь квантуется до 0.001 «половиной вверх» и на сервере
  (`sale_service._area`, до цены и списания), и в кассе (`utils/area.js`,
  целочисленно по десятичной записи); «Вся сумма» шлёт `pay_full`, поле
  показывает живой итог, ручной ввод снимает флаг; `quantity` в checkout
  принимает 3 знака (продажа площади 0.554 кв.м раньше падала с 400).
  Проверка: тот же кусок → касса 0.554 / 831 / **979**, чек **979**,
  «Оплачено», без долга ([150-fix2-cut-modal.png](150-fix2-cut-modal.png),
  [152-fix2-receipt-modal.png](152-fix2-receipt-modal.png),
  [154-fix2-receipts.png](154-fix2-receipts.png)). Тесты
  `sales/tests_rounding.py`.

### 4. Финансы: две «Прибыли» на одном экране — −14 265 и +3 735

### 10. Цена листа расходится между Складом и Продажей

- Скрины: [04-empty-catalog.png](04-empty-catalog.png) — «Белый акрил: 1250
  сом/кв.м, **3725** сом/лист»; [01-empty-checkout.png](01-empty-checkout.png)
  — та же плитка в кассе «**3700** сом/лист». Для созданного «Акрил 3мм»: Склад
  **4465** ([13-A-catalog-after-create.png](13-A-catalog-after-create.png)),
  касса **4466** ([30-B-cut-modal-default.png](30-B-cut-modal-default.png)).
- Причина: Склад показывает `Math.round(price_per_sqm × piece_area)`
  (`Catalog.jsx::PriceCell`), не трогая поле `piece_price`, по которому реально
  продают; касса показывает `ceil(piece_price)`. Заказчик сверяет именно эту
  цифру с Excel.
- ✅ **Починено:** розничная строка «сом/лист» в Складе — это `piece_price` с
  тем же округлением вверх, что в кассе; нет цены за лист — нет и строки (в
  кассе продажа целиком тогда недоступна). Закупочная «за лист» по-прежнему

### 11. Окно «Правка чека»: итог меняется от одного открытия

- Скрин: [43-B-edit-receipt-r1.png](43-B-edit-receipt-r1.png) — открыли чек
  №1, ничего не трогали: «Итого ~~979~~ **980** сом».
- Причина: `Math.ceil(0.554 × 1500)` в JS = `Math.ceil(831.0000000000001)` =

  (`EditReceiptModal.jsx:52`).
- ✅ **Починено:** тот же `ceilSom` с эпсилоном. Открыли чек №1 — «Итого 979»,
  без стрелки ([219-fix11-edit-modal-total.png](219-fix11-edit-modal-total.png)).

## Как это гонялось

Скрипты Playwright лежат в scratchpad сессии (`…/scratchpad/pw/*.js`, общий
`lib.js` — логин, скриншот с автосканом текста, API-обёртка). Каждый шаг делал
`page.screenshot({fullPage})`, файл открывался и просматривался глазами;
числа сверялись с ответами API (`/api/sales/receipts/`, `/api/audit/dashboard/`)
и с ручным расчётом.
